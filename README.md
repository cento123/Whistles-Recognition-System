
# Whistles Recognition System (WRS) Model Testing

This project provides scripts to test a WRS model described in the paper:
'Exploring You Only Look Once v8 for automatic detection of dolphin whistles in spectrograms'

Avaria-Avaria, V.; Diego-Tortosa, D.; Gallardo, C.; Morell-Monzó, S.; & Quiroz-Rangel, C. A. (2026). *Exploring You Only Look Once v8 for automatic detection of dolphin whistles in spectrograms*. Bioacoustics, 35(2), 148–174. https://doi.org/10.1080/09524622.2025.2612276

If you use this repository in a research, a citation to this article would be appreciated.

It is designed for whistle recognition tasks and includes functionality to evaluate model performance and visualize
detection results.

## Features

- Test WRS models on custom datasets
- Visualize and save detection results with bounding boxes and class labels
- Save json results for further analysis
- Configurable parameters via command-line arguments

## Requirements

Python 3.11 or higher is required. It is recommended to use a virtual environment to manage dependencies.
```bash
Python >= python3.11

python3.X -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install --upgrade pip
```

Install dependencies using pip:

```bash
pip install -r requirements.txt
```

## WRSapplication Usage

This command analyzes images from a given directory (it also processes images inside subfolders):
```bash
python -m scripts.WRSapplication --model <path_to_model.pt> --data <path_to_test_images> --output_results <results_folder>
```

### WRSapplication Optional Arguments

- `--conf`: Confidence threshold (default: 0.50)
- `--iou`: IoU threshold for NMS (default: 0.25)
- `--batch_size`: Batch size for testing (default: 16)
- `--device`: Device to run the model (`cpu` or `cuda`, default: `cpu`)
- `--filename_contains`: Optional substring that filenames must contain.
- `--image_extension`: File extension of images to process: `.png`, `.jpg`, etc. (default: `.png`)

## WRSapplication Output

- Detection results are saved in the specified results folder with bounding boxes (`json` files) and class labels drawn on the images.

## WRSresults Usage

This command analyzes the results generated by WRSresults:
```bash
python -m scripts.WRSresults --data_folder <path_to_test_results_WRSapplication> --output_results <results_folder>
```

### WRSresults Optional Arguments
- `output_hist`: If set, saves histograms for each calculated parameter (default: False)
- `output_name`: Base name for output files (`CSV`, `plots`). Default: `script_name`.

## WRSresults Output

- It extracts `Tdur` (time duration [s]), `Fmin` (minimum frequency [Hz]), `Fmax` (maximum frequency [Hz]), and `Fdur` (frequency bandwidth [Hz]), and generates a `CSV` file along with plots to visualize the results.

## Project Structure

- `scripts/WRSapplication.py`: script to run Whistles-Recognition-System on images and save the results
- `scripts/WRSresults.py`: script to analyze WRSapplication results from the output JSON files
- `src/utils.py`: utils functions used by the scripts
- `models/`: Directory to store trained WRS model weights from "Phase 3: training with all data"
- `images/`: Directory containing test images from main dataset (H1) used in "Phase 1: experimenting with whistles and pings"
- `images/` --> `gt`: Ground truth annotations for test images
- `results/`: Directory to save output results
- `requirements.txt`: Python dependencies
